# Myblog

A blog which contains all the essential functions.

Written using [Django Framework](https://djangoproject.com) with TailwindCSS support ([Django-Tailwind](https://django-tailwind.readthedocs.io/en/latest/index.html)) and [DaisyUI](https://daisyui.com/) for UI handling and components. As for the DBMS, Postgres was used.

__Note:__ This project was commissioned for by [Data & Media Lab](https://dmlab.edu.gr)
